# VideoSaver

Личное Android-приложение для скачивания видео по ссылке: YouTube, Instagram, TikTok и прямые ссылки на файлы
(всё, что умеет [yt-dlp](https://github.com/yt-dlp/yt-dlp)).

- **Дизайн:** Material 3, цвета подстраиваются под системную палитру телефона (Material You, Android 12+),
  светлая и тёмная темы переключаются автоматически.
- **Как пользоваться:** вставьте ссылку и нажмите «Скачать». Или в YouTube / Instagram / TikTok нажмите
  «Поделиться» → **VideoSaver**, и загрузка начнётся сразу.
- **Качество:** Лучшее / 1080p / 720p / 480p / Только звук (m4a).
- **Куда сохраняется:** видео в `Movies/VideoSaver`, звук в `Music/VideoSaver` — файлы сразу видны в галерее.
- **Фон:** загрузки идут в фоне с уведомлением и прогрессом.
- **Обновление yt-dlp:** автоматически раз в 12 часов и вручную кнопкой вверху. Сайты часто меняются,
  без обновлений скачивание со временем ломается.

Требования к телефону: Android 10+ (динамические цвета — Android 12+, на 10–11 используется запасная синяя палитра).

## Как получить .apk (без установки Android Studio)

1. Создайте репозиторий на [github.com](https://github.com) (лучше **приватный**) и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** → **Build APK** → **Run workflow** (сборка также запускается при каждом коммите).
3. Через 5–10 минут откройте завершённый запуск, внизу в разделе **Artifacts** скачайте `VideoSaver-apk`
   (внутри ZIP лежит `VideoSaver.apk`).
4. Перенесите APK на телефон и установите (разрешите установку из неизвестных источников).

Если создать тег `v1.0`, APK ещё и прикрепится к странице **Releases**: скачивать удобнее прямо с телефона.

### Либо локально
Откройте папку в Android Studio (Ladybug или новее) и выполните **Build → Build APK(s)**, либо в терминале:

```
./gradlew assembleRelease
```

Готовый файл: `app/build/outputs/apk/release/app-release.apk`.

## Подпись

APK подписывается личным ключом `app/keystore/personal.jks` (пароль `videosaver`), поэтому новые версии
ставятся поверх старых без удаления. Ключ лежит в репозитории только для удобства личной сборки: держите
репозиторий приватным, а для публикации в Google Play создайте собственный ключ.

## Ограничения

- **Instagram** часто требует вход в аккаунт, поэтому закрытые аккаунты и часть публикаций не скачаются.
  Публичные посты и Reels обычно работают.
- **YouTube** иногда просит подтвердить, что вы не бот; помогает обновление yt-dlp или повтор позже.
- Список загрузок хранится только пока приложение запущено, но сами файлы остаются в галерее.
- Скачивайте только то, на что у вас есть право: свои видео, контент с разрешением автора, материалы без
  ограничений. Правила YouTube, Instagram и TikTok скачивание обычно запрещают.

## Структура

```
app/src/main/java/com/videosaver/app/
  App.kt                  запуск движка yt-dlp при старте
  MainActivity.kt         точка входа, приём ссылок из «Поделиться»
  DownloadRepository.kt   очередь, прогресс, параметры yt-dlp, сохранение в MediaStore
  DownloadService.kt      foreground-сервис и уведомления
  Models.kt               модели, настройки, извлечение ссылки из текста
  ui/Theme.kt             Material 3 + динамические цвета
  ui/MainScreen.kt        экран приложения
```

Качество и формат настраиваются в `DownloadRepository.buildRequest()`.
